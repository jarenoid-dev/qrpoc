# Evidence storage

Create one directory per case-study step:

`YYYY-MM-DD-NNN-short-slug/`

Keep baseline, prototype, result, and annotation files together. Use numbered lowercase ASCII filenames so the sequence is clear. The corresponding step record must explain what each file proves and must include the route, state, viewport, date, and stable prototype or commit reference.

Do not place secrets, credentials, private customer data, or files above 25 MB in this directory.
