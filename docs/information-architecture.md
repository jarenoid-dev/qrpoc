## App Map

Every surface is entered from the shared **QRPOC** hub. Customer, Kitchen, Waiter, and Service Manager are single linear task flows — each step leads to the next. The Admin Panel is a flat set of management modules with no fixed order.

### 1. Customer (Müşteri)
Menu → Customization → Order

### 2. Kitchen (Mutfak)
New → In Progress → Ready

### 3. Waiter (Garson)
Table → Order → Check

### 4. Service Manager (Servis Müdürü)
Overview → Requests → Exceptions

### 5. Admin Panel (Yönetim Paneli)
Analytics · Menu · Recipes · Operational Settings · QR / Tables · Integrations · Inventory · Purchasing
